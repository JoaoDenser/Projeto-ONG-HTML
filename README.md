# 🌿 Salvando a Mata

## 📌 Sobre o projeto

O Salvando a Mata é um projeto acadêmico desenvolvido com o objetivo de representar um site para uma ONG voltada à preservação ambiental. A proposta é conscientizar as pessoas sobre a importância da natureza e incentivar a participação em ações voluntárias.

## 🎯 Objetivo

Desenvolver um site informativo, acessível e responsivo, que apresente a ONG, seus projetos ambientais e permita que pessoas interessadas realizem um cadastro para participar como voluntárias.

## 🛠️ Tecnologias utilizadas

* **HTML5:** utilizado para estruturar o conteúdo das páginas.
* **CSS3:** utilizado para estilizar o site, definir cores, fontes, layouts e responsividade.
* **JavaScript:** utilizado para implementar funcionalidades interativas.
* **Git e GitHub:** utilizados para controlar as versões e organizar o desenvolvimento do projeto.

## ✨ Funcionalidades

* Página inicial com apresentação da ONG.
* Seção sobre a organização.
* Apresentação dos projetos ambientais.
* Menu de navegação.
* Formulário de cadastro de voluntários.
* Validação dos campos do formulário.
* Layout responsivo para diferentes dispositivos.

## 🚀 Como executar o projeto

1. Acesse o repositório do projeto no GitHub.
2. Faça o download dos arquivos ou clone o repositório.
3. Abra a pasta do projeto.
4. Abra o arquivo `index.html` em um navegador.
5. Para acessar o cadastro de voluntários, utilize o menu de navegação ou abra o arquivo `cadastro.html`.

Não é necessário instalar dependências externas para executar o projeto.

## 🧪 Testes e validação

O projeto pode ser testado diretamente no navegador, verificando:

* Funcionamento dos links e menus.
* Navegação entre as páginas.
* Preenchimento e validação dos campos do formulário.
* Adaptação do layout em diferentes tamanhos de tela.
* Validação do código HTML por meio do W3C Validator.

## 🌱 Considerações finais

O projeto Salvando a Mata foi desenvolvido como uma atividade acadêmica, proporcionando a aplicação prática dos conhecimentos de desenvolvimento web, organização de código, responsividade e controle de versões.

A proposta é demonstrar como a tecnologia pode contribuir para a divulgação de iniciativas ambientais e incentivar a participação da comunidade na preservação da natureza.
